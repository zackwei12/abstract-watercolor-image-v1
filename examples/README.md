# Examples

Add author-created example outputs here.

Recommended example set:

1. group photo → overlapping abstract watercolor blocks
2. single standing figure → vertical stacked masses
3. crouched figure → low angular cluster
4. busy scene → simplified 8 to 12 block composition
5. object-heavy reference → essential masses only
6. high-abstraction version → nearly non-figurative but compositionally related

For each example, avoid uploading source photos unless you have permission to publish them. Prefer showing only generated outputs or use public-domain / self-owned source material.

When examples are added, reference them from the main README in a simple two-column gallery.
